# Anthbot Map v2.4.1-beta.3

## Battery-saver dialog UI correction

- Removes the checkbox from the Battery saver settings tile. The complete tile
  now only opens the configuration dialog and never toggles the mode directly.
- Keeps the Battery saver mode enable/disable control inside the dialog and
  enlarges its checkbox to 28 × 28 pixels for clearer desktop and touch use.
- Adds regression coverage for both UI requirements.

This is a beta / pre-release build intended for validation before the next
stable release.

# Anthbot Map v2.4.1-beta.3 – magyar

## Az akkumulátorkímélő popup felületének javítása

- Eltávolítja a pipát az Akkumulátorkímélő beállítások csempéről. A teljes
  csempe kizárólag a beállítóablakot nyitja meg, közvetlenül nem kapcsolja a
  módot.
- Az Akkumulátorkímélő mód be-/kikapcsolása a popupban marad, a jelölőnégyzet
  pedig 28 × 28 pixeles, így asztali és érintős felületen is jól látható.
- Regressziós teszt védi mindkét felületi követelményt.

Ez **béta / előzetes kiadás**, a következő stabil verzió előtti teszteléshez.
