# Anthbot Map v2.0.0-beta.3 – magyar változásnapló

## Javítás

- A zónanyírás gombjai akkor sem tűnnek el, ha a térképentitás átmenetileg
  `unavailable` állapotú.
- A kártya közvetlenül megkeresi a natív `Zone 1`, `Zone 2`, `Zone 3` Home
  Assistant gombentitásokat, és ezekből építi fel a zónanyírási csempéket.
