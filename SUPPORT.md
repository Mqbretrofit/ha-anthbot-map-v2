# Support Anthbot Map development

Anthbot Map is an independent, unofficial community project for Home Assistant. Development includes protocol research, real-device testing, map and path decoding, model-specific behavior, diagnostics, translations, regression fixes, and support for new ANTHBOT mower models.

If the project is useful to you, you can help keep development sustainable in several ways.

## GitHub Sponsors

Use the **Sponsor** button on the repository to support ongoing development through GitHub Sponsors.

Suggested monthly tiers:

- **Supporter — €3/month**: support continued maintenance and bug fixes.
- **Sponsor — €7/month**: help fund testing, diagnostics, and compatibility work.
- **Development Sponsor — €15/month**: help fund new features and new-model research.
- **Project Sponsor — €30–50+/month**: for users or businesses that want to materially support continued development.

The integration remains an open-source community project. Sponsorship does not buy control over the roadmap or guarantee that a requested feature can be implemented.

## Sponsor a feature

If you need a specific feature, mower model, protocol investigation, or compatibility improvement, open a **Sponsored feature request** issue.

Typical contribution ranges:

- small, well-defined feature: **€50–100**
- larger feature or protocol investigation: **€100–300**
- substantial new-model support or work requiring significant device/protocol research: **€300–500+**

These are indicative ranges only. Scope, feasibility, hardware requirements, and the final contribution amount should be agreed before development starts.

Sponsored work is normally contributed back to the public project so the whole community benefits.

## Priority troubleshooting / development support

For complex installation problems, diagnostics, protocol captures, or device-specific investigations, priority support can also be agreed separately. Please open an issue first and do not post passwords, tokens, API credentials, serial numbers that should remain private, or other secrets publicly.

## Independence

Anthbot Map is not affiliated with, endorsed by, or supported by ANTHBOT. Sponsorship supports this independent community project and its development work; it does not purchase any ANTHBOT product, cloud service, firmware, or proprietary vendor material.

# A fejlesztés támogatása

Az Anthbot Map egy független, nem hivatalos Home Assistant közösségi projekt. A fejlesztés része a protokollkutatás, a valódi eszközökön végzett tesztelés, a térkép- és útvonaladatok feldolgozása, a modellenkénti működés, a diagnosztika, a fordítások, a hibajavítások és az új ANTHBOT modellek támogatása.

A fejlesztést a repository **Sponsor** gombján keresztül lehet támogatni.

Javasolt havi támogatási szintek:

- **Supporter — €3/hó**
- **Sponsor — €7/hó**
- **Development Sponsor — €15/hó**
- **Project Sponsor — €30–50+/hó**

Konkrét funkció vagy új modell támogatása külön **Sponsored feature request** issue-ban kérhető. Irányadó hozzájárulási sávok: kisebb funkció **€50–100**, komolyabb fejlesztés vagy protokollvizsgálat **€100–300**, jelentős újmodell-támogatás vagy hardveres/protokollos kutatás **€300–500+**.

Ezek tájékoztató összegek. A pontos feladatot, megvalósíthatóságot, hardverigényt és támogatási összeget a munka megkezdése előtt kell egyeztetni. A támogatott fejlesztések alapértelmezetten bekerülnek a nyilvános projektbe.
