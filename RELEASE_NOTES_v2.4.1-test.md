# Anthbot Map v2.4.1-test

## Battery saver test update

- Adds four battery-saver profiles: Maximum battery care (60–80%), Balanced (65–80%, recommended), Always ready (80–90%), and Custom.
- Keeps the option for installations where the charging station and RTK share the same smart plug.
- Adds the 55-minute standby anti-shutdown guard: while docked and idle with charger power off, the charger is powered for one minute, then switched off and the cycle restarts.
- The short-charge guard yields to normal charging, mowing/tasks, dock departure, and disabled battery-saver mode.
- Completes the battery-saver dialog translations for all 23 supported languages and fixes translation priority/cache handling.
- Interrupted-task resume level remains separate from the standby charging range.

This is a **test / pre-release build** intended for validation before the next stable release.
