# ANTHBOT Map developer reporting privacy information

Developer reporting is optional and disabled by default. The ANTHBOT Map integration works without enabling either reporting option.

## Anonymous usage statistics

If **Share anonymous usage statistics with the developer** is enabled, the integration sends a small report when the integration is installed or when an existing installation is opted in later.

The payload contains:

- a random installation identifier generated by the integration;
- ANTHBOT Map integration version;
- Home Assistant version;
- the country selected for the ANTHBOT account;
- the number of discovered mowers;
- mower model names and counts.

The anonymous usage payload does **not** contain the ANTHBOT username, email address, password, mower serial number, mower alias, GPS coordinates, map geometry, mowing path, bearer token, AWS credentials or other cloud authentication secrets.

As with any HTTPS request, normal network infrastructure necessarily processes connection metadata such as the source IP address. The integration does not add the IP address to the telemetry JSON payload.

## Automatic diagnostics

If **Send automatic diagnostics when a relevant error is detected** is enabled, the integration may upload a technical diagnostics report when a supported diagnostic trigger occurs. Diagnostics can include mower model and firmware information, robot state, path data, no-go geometry and related technical information needed to reproduce a fault.

The diagnostics builder redacts credential-like fields such as passwords, tokens, authorization values, cookies and cloud credentials. Full raw coordinator state is excluded by default.

## Changing your choice

Both reporting options are independent. They can be disabled later from the ANTHBOT Map integration options. Disabling an option stops future uploads for that category.

## Purpose

Anonymous usage statistics are used to understand how many installations use the integration and which ANTHBOT models, countries and Home Assistant versions need support. Diagnostics are used to reproduce integration or firmware-related problems and improve compatibility.

No developer reporting option is required for normal mower control or map functionality.
