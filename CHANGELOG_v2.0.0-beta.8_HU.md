# Anthbot Map v2.0.0-beta.8 – magyar változásnapló

## Egyszerűbb telepítés és tesztelés

- A teljes Anthbot Map kártya bekerült az integráció saját csomagjába.
- A HACS mostantól az integrációval együtt automatikusan frissíti a JavaScript,
  CSS, renderer, fordítási és képfájlokat.
- Többé nem kell a release ZIP-ből a `/config/www/anthbot-map-v2` mappába
  kézzel másolni.
- Az új erőforrás URL: `/anthbot-map-v2/anthbot-map-card.js`.
- A régi `/local/anthbot-map-v2` mappa megmaradhat visszaállítási lehetőségnek.
